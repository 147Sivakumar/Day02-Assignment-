# Day02-Assignment-

## Grade System

This project is a Python program that accepts a mark between 0 and 100 and converts it into the corresponding letter grade.

### Grading Scale

* 90–100 → A
* 80–89 → B
* 70–79 → C
* 60–69 → D
* Below 60 → E

### Invalid Input Handling

I used `try-except` to handle input that is not a number, such as letters or words, so the program does not crash. I also check whether the mark is between 0 and 100 and display an error message if the value is outside this range.

### Files

* `grade_system.py` — Python program for calculating the grade.
